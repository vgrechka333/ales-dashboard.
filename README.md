# Дашборд регистраций из Salebot — инструкция для новичка

Что это делает: каждые 5 минут платформа сама заходит в твой Salebot по API-ключу
и забирает список клиентов бота, считает регистрации и рисует график.
Тебе не нужно ничего настраивать в самом боте — только дать платформе ключ и ID.

Ничего в терминале печатать не придётся. Всё — мышкой в браузере.

---

## Шаг 1. Собери два значения из Salebot

1. Зайди в свой аккаунт Salebot.pro → **Настройки проекта → API**. 
2. Скопируй **API-ключ** (длинная строка из букв и цифр). Если ключа ещё нет — там же
   есть кнопка «Сгенерировать».
3. Найди **ID бота** (group_id) — он нужен, только если в проекте несколько ботов
   и тебе нужны регистрации именно одного из них. Посмотреть список ботов и их ID можно
   в разделе **Мессенджеры и чаты** (у Telegram-бота ID обычно выглядит как имя бота,
   заканчивающееся на `bot`). Если бот один — этот шаг можно пропустить.

Сохрани оба значения куда-нибудь рядом — они понадобятся на шаге 4.

---

## Шаг 2. Залей код на GitHub (без команд, просто перетаскиванием файлов)

1. Зарегистрируйся на [github.com](https://github.com), если ещё нет аккаунта — это бесплатно.
2. Нажми **New repository** (зелёная кнопка справа вверху на главной).
3. Дай название, например `sales-dashboard`, оставь «Public» или «Private» — как удобно, жми **Create repository**.
4. На странице пустого репозитория нажми **uploading an existing file**.
5. Перетащи в окно браузера ВСЕ файлы и папки из скачанного архива (`server.js`,
   `package.json`, `public/`, `.env.example`, `README.md`) — просто разархивируй
   архив на компьютере и перетащи содержимое папки целиком.
6. Внизу нажми **Commit changes**.

Готово — код лежит на GitHub.

---

## Шаг 3. Разверни на Railway (работает 24/7, не засыпает)

1. Зайди на [railway.app](https://railway.app) и войди через свой GitHub-аккаунт.
2. Нажми **New Project → Deploy from GitHub repo**.
3. Выбери репозиторий `sales-dashboard`, который ты только что создал.
4. Railway сам определит, что это Node.js-проект, и начнёт разворачивать.

---

## Шаг 4. Впиши ключ и ID (переменные окружения)

1. В проекте на Railway открой сервис → вкладка **Variables**.
2. Добавь три переменные (кнопка **New Variable**):
   - `SALEBOT_API_KEY` — вставь ключ из Шага 1
   - `SALEBOT_GROUP_ID` — вставь ID бота из Шага 1 (если пропустил — просто не добавляй эту переменную)
   - `POLL_INTERVAL_MINUTES` — можно поставить `5`
3. Сохрани — Railway автоматически перезапустит сервис с новыми настройками.

---

## Шаг 5. Открой дашборд

1. Во вкладке **Settings** сервиса найди **Networking → Generate Domain** — нажми,
   Railway выдаст публичный адрес вида `https://sales-dashboard-production.up.railway.app`.
2. Открой этот адрес в браузере — это и есть твой дашборд. Он работает постоянно,
   даже если ты закроешь браузер или выключишь компьютер — сервер крутится на Railway.

Первые данные появятся в течение 5 минут после запуска (время на первый опрос Salebot).

---

## Сколько это стоит

Railway даёт стартовый бесплатный баланс, дальше — по факту использования,
для такого лёгкого сервиса это обычно единицы долларов в месяц. Карту привязать
попросят при создании аккаунта или когда бесплатный баланс закончится.

---

## Если что-то не так

- **На дашборде долго "—" вместо цифр** — подожди 5 минут (это интервал опроса) и обнови страницу.
- **В логах Railway (вкладка Deployments → View Logs) ошибка от Salebot** — значит
  неверный `SALEBOT_API_KEY` или `SALEBOT_GROUP_ID`. Перепроверь их в настройках Salebot.
- **Нужно чаще обновлять данные** — уменьши `POLL_INTERVAL_MINUTES` в Variables на Railway,
  например до `1`.
